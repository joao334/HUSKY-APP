HUSKY CONFEITEIRO - SISTEMA CLIENTE + GESTÃO + INFINITEPAY

Arquivos principais:
- index.html: app do cliente
- gestao.html: app da gestão
- retorno-pagamento.html: tela que recebe o cliente depois do pagamento
- config.js: configuração pública do Supabase e InfinitePay
- SUPABASE_SQL_COMPLETO.sql: banco completo
- SQL_INFINITEPAY_CHECKOUT.sql: patch do pagamento InfinitePay
- edge-functions/create-infinitepay-checkout/index.ts
- edge-functions/infinitepay-webhook/index.ts
- edge-functions/check-infinitepay-payment/index.ts

INFINITETAG CONFIGURADA:
$huskybolos
No código a tag fica sem o símbolo $, como a InfinitePay pede:
huskybolos

FLUXO DE PAGAMENTO:
1. Cliente monta a sacola.
2. Cliente entra/cadastra.
3. Cliente clica em pagar.
4. App chama a Edge Function create-infinitepay-checkout.
5. A função cria o link em https://api.checkout.infinitepay.io/links.
6. Cliente é redirecionado para a InfinitePay.
7. Cliente paga com Pix ou cartão.
8. InfinitePay chama o webhook infinitepay-webhook.
9. O webhook marca checkout_sessions como pago, cria payments, customer_orders e order_items.
10. O pedido aparece na gestão e o estoque é baixado.

IMPORTANTE:
Não existe botão "já paguei" liberando pedido.
O pedido só aparece na gestão quando o webhook da InfinitePay confirma o pagamento.

CONFIG.JS:
Confirme estes campos:
- supabaseUrl
- supabaseAnonKey
- infinitePayHandle: "huskybolos"
- checkoutFunction: "create-infinitepay-checkout"
- checkFunction: "check-infinitepay-payment"
- paymentReturnUrl: "https://husky-app.vercel.app/retorno-pagamento.html"

SUPABASE:
1. Rode SUPABASE_SQL_COMPLETO.sql.
2. Rode SQL_INFINITEPAY_CHECKOUT.sql.
3. Crie/publique as Edge Functions:
   - create-infinitepay-checkout
   - infinitepay-webhook
   - check-infinitepay-payment
4. Configure os secrets das funções:
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY
   SITE_URL=https://husky-app.vercel.app
   INFINITEPAY_HANDLE=huskybolos
   INFINITEPAY_REDIRECT_URL=https://husky-app.vercel.app/retorno-pagamento.html
   INFINITEPAY_WEBHOOK_URL=https://SEU-PROJETO.supabase.co/functions/v1/infinitepay-webhook

VERCEL:
Suba todos os arquivos na raiz do projeto.
Acesse:
Cliente: https://husky-app.vercel.app/
Gestão: https://husky-app.vercel.app/gestao.html
Retorno pagamento: https://husky-app.vercel.app/retorno-pagamento.html

OBSERVAÇÃO:
A InfinitePay retorna o cliente para a URL de retorno, mas a confirmação real acontece pelo webhook.
Se o cliente voltar antes do webhook processar, a tela de retorno mostra "aguardando confirmação" e permite verificar novamente.
